# 🏢 신우 공인중개사 | AI 네이버 블로그 & 인포그래픽 자동 생성기

> **부동산 뉴스, 정비사업 분석, 현장 매물 룸투어, 3분 카드뉴스**를 주제나 사진, 파일만 넣으면 최신 기사를 검색하고 고화질 인포그래픽 차트와 위치도를 곁들여 네이버 블로그 완성 글로 작성해주는 **Windows 무설치 고속 실행 포터블 데스크톱 프로그램**입니다.

---

## ✨ 핵심 기능 및 특징

### 1. 4대 맞춤형 글감 및 포스팅 모드
- **📰 부동산 뉴스/정책 분석**: 최신 인터넷 기사와 국토부 보도자료를 실시간 검색(연합뉴스·네이버 뉴스 하이브리드)하여 공인중개사의 독창적인 시각과 영향 평가, 실무 가이드로 재해석합니다.
- **🏠 현장 사진 매물 소개 (신축·기축·분양권·입주권 특화)**:
  - **기축 매물(기존 완공 주택 매매/전세/월세)**: 이미 완공된 주택의 특성에 맞춰 건축 용어('준공 완료' 등)를 배제하고 **점유 상태 및 실제 입주 가능 시기**(`🔑 즉시 입주 가능 (현재 공실)`, `정상 입주 협의`)로 명확히 안내.
  - **신축 첫 입주**: `✨ 신축 첫 입주 (준공/사용승인 완료)` (공정률 100%).
  - **공사 중 분양권**: 골조/마감 실제 현장 공정률(60~75%) 및 입주 예정 시기 반영.
  - **재개발·재건축 입주권**: 해당 구역 실제 사업 단계(`사업시행인가 완료`, `관리처분인가 완료`, `이주·철거`) 및 추진율(55~80%) 반영.
  - 여러 장의 실제 현장 사진(거실, 주방, 침실, 욕실 등)을 등록하면 AI가 공간별 특징을 순서대로 분석하여 생생한 룸투어 포스팅 작성.
- **⚡ 3분 요약 카드뉴스 (Slide Card News)**:
  - 모바일 독자의 스크롤 편의를 위해 본문을 `[카드 01]~[카드 06]` 슬라이드 단위로 분할 구성.
  - 네이버 블로그 스마트에디터 ONE 전용 **슬라이드 카드 글상자 서식**(모던 테두리, 카드 넘버링 뱃지)으로 원클릭 복사 지원.
- **📁 문서/자료 분석**: HWP, HWPX, PDF, DOCX 등 분양 공고문이나 계획 문서를 첨부하면 핵심을 1초 만에 분석하여 요약 포스팅.

### 2. AI 실시간 인포그래픽 차트 자동 생성 (0.05초 초고속 QPainter 벡터 그래픽)
- 외부 의존성(matplotlib 등) 없이 PyQt6 내장 벡터 그래픽으로 **0.05초 만에 고해상도 대시보드 카드(620x400, 네이버 블로그 1:1 최적화)**를 실시간 렌더링.
- **분야별 4대 지표 카드 & 프로그레스 바**:
  - **정비사업**: 총 건립 세대, 시공사 브랜드, 추진 현황, 단지 규모 + 추진단계 로드맵(20~100%).
  - **매물 브리핑**: 매물 구분, 가격 조건, 면적 및 구조, 소재지 위치 + 점유/입주 상태 바 + 특장점 프리미엄 하이라이트.
  - **정책/금융**: 가산 금리, 적용 대상, 한도 영향, 실전 대응 전략 2x2 그리드.
- **원클릭 클립보드 복사**: 상단 `[📊 차트 복사]` 버튼 클릭 후 네이버 스마트에디터 원하는 위치에 `[Ctrl + V]`로 붙여넣으면 고해상도 사진으로 바로 삽입.

### 3. 정비구역 위치도 자동 합성 & 국토부 토지이음 뷰어 연동
- 오픈 타일맵(OSM) 기반으로 별도 API 키나 워터마크 없이 16:9 비율의 정비구역 위치도 및 지적 약도 자동 합성 생성.
- 상단 `[🗺️ 구역 지도 복사]`로 블로그 본문에 원클릭 사진 첨부.
- 국토교통부 공식 **'토지이음(eum.go.kr)'** 정비구역 지도 뷰어 1초 다이렉트 팝업 연동.
- 거시 정책 뉴스는 지도를 자동 생략하고, 실제 지리적 위치가 있는 주제만 본문 입지 설명 부근에 정확히 1회 스마트 배치.

### 4. 전역 이모지 중복 방지 & 스마트 텍스트 정제 엔진
- **유니코드 기반 중복 축약**: AI가 강조를 위해 연속 출력하는 이모지(`⚡ ⚡` ➔ `⚡`, `🔍 🔍` ➔ `🔍`, `😊 😊` ➔ `😊`)를 유니코드 정규식 토큰 엔진(`services/text_utils.py`)으로 1개로 자동 축약.
- **플레이스홀더 및 라벨 중복 정제**:
  - `[✨ 추천 스티커: ✨ 박수]` ➔ `[✨ 추천 스티커: 박수]` 자동 정제.
  - 인포그래픽 차트 4대 지표 카드에 중복 아이콘(`🏢 🏘️`)이 붙지 않도록 선행 이모지 자동 감지.
  - 프로그레스 바 상태 텍스트(`🔑 입주 상태: 🔑 ...`) 중복 방지.
- **무관 안내문 본문 삽입 차단**: 블로그 작성자를 위한 조작 안내문('상단 버튼 복사 후 붙여넣기' 등)은 본문에서 완전 배제하고 프로그램 UI 안내창으로 분리 제공.

### 5. 네이버 블로그 스마트에디터 ONE 100% 맞춤 복사
- 볼드체, 소제목, 정책 전/후 **비교표(Table)**, 슬라이드형 카드 글상자 서식이 완벽하게 유지된 채 클립보드에 복사.
- 글 하단에 공인중개사 사무소 상호명, 대표자명, 등록번호, 전화번호, 상담 링크 명함 배너 자동 삽입.

## 🚀 빠른 시작 (실행 방법)

### 방법 1. 원클릭 실행 (추천)
- 프로젝트 루트의 **`실행하기.bat`**를 더블클릭하면 0.5초 이내에 프로그램이 즉시 실행됩니다.

### 방법 2. 파이썬 직접 실행
```bash
# 가상환경 활성화 후 의존성 설치
pip install -r requirements.txt

# 프로그램 실행
python app.py
```

## 🔑 초기 설정 (최초 1회)

1. 프로그램 상단 우측의 **`⚙️ 환경 설정 (API 키)`** 버튼을 클릭합니다.
2. [Google AI Studio](https://aistudio.google.com/)에서 무료 발급받은 **Gemini API 키**를 입력합니다.
   - 기본 권장 모델: **`gemini-3.6-flash`** (빠르고 정확한 최신 모델)
3. 부동산 상호명, 대표자명, 전화번호, 사무소 주소를 입력해 두면 모든 포스팅 하단에 신뢰감 있는 명함 배너가 자동으로 부착됩니다.
4. (선택) 네이버 뉴스 검색 API Client ID/Secret을 등록하면 더 정밀한 검색이 지원됩니다.

## 🛠️ 패키징 및 빌드 안내

### 1. 초고속 포터블 폴더형 빌드 (추천 - 0.5초 즉시 실행)
```bash
python build_portable.py
```
- `dist/공인중개사_블로그_생성기/` 폴더가 생성됩니다.
- 압축 해제 딜레이 없이 실행 파일 더블클릭 시 **0.5초 만에 즉시 구동**됩니다.

### 2. 단일 파일 (.exe 1개) 빌드
```bash
python build_portable.py --onefile
```
- 불필요한 대형 패키지(matplotlib, tkinter, pandas 등)를 제외한 경량화된 단일 `.exe`가 생성됩니다.

## 🧪 통합 테스트 (자동화 검증)

프로젝트 핵심 기능이 정상 동작하는지 테스트 스위트로 언제든 검증할 수 있습니다:

```bash
python tests/test_integration.py
```

**검증 항목 (5대 테스트 통과)**:
1. `test_zone_extraction`: 구역명 및 위치 키워드 자동 탐색 검증
2. `test_hannam_case`: 재개발 뉴스 비정형 지도 생성, 인포그래픽 데이터 파싱, 중복 방지 검증
3. `test_policy_case`: 거시/정책 뉴스 시 지도 자동 생략 및 체크포인트 카드 검증
4. `test_card_news_case`: 3분 카드뉴스 포맷 감지, 슬라이드 분할, 스마트에디터 박스 서식 검증
5. `test_emoji_deduplication`: 본문, 차트, 플레이스홀더 전역 이모지 중복 방지 검증
