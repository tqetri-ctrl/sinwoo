# 🏢 신우 공인중개사 | AI 네이버 블로그 글 생성기 (AI 부동산 브리핑)

부동산 새 소식, 시장 동향, 분양 공고문, 보도자료를 **주제나 파일만 넣으면 최신 기사를 검색하고 이모티콘과 서식을 곁들인 네이버 블로그 글**로 자동 완성해주는 **Windows 무설치 단일 파일(.exe) 포터블 프로그램**입니다.

---

## ✨ 주요 기능 및 특징

1. **초보자도 쉽게 쓰는 1-2-3-4 단계 UI (3대 글감 모드)**:
   - **🏠 현장 사진 매물 소개 (NEW)**: 매매/전세/월세/분양 등 거래유형 및 가격/스펙 입력 + 여러 장의 실제 현장 사진(거실, 주방, 룸, 욕실 등)을 올려 생생한 룸투어 포스팅 작성!
   - **📰 부동산 뉴스/정보**: 최신 인터넷 기사와 정책 팩트를 자동으로 실시간 검색 및 심층 분석하여 포스팅.
   - **📁 문서/자료 분석**: 보도자료, 분양 공고문, HWP, HWPX, PDF, DOCX 등 첨부문서 정밀 요약 포스팅.
2. **현장 사진 다중 분석 & 생생한 룸투어 브리핑**:
   - 한 번에 여러 장의 현장 사진을 등록하면 AI가 사진의 공간과 특징(채광, 뷰, 마감상태, 수납공간 등)을 순서대로 분석하여 `[📸 사진 1: 거실 - ...]`, `[📸 사진 2: 주방 - ...]` 등의 사진 가이드와 함께 매력적인 매물 설명 글 작성.
3. **매물 핵심 요약 Check Point & 스마트에디터 완벽 호환**:
   - 소재지, 가격, 면적, 층수, 관리비 등을 한눈에 볼 수 있는 깔끔한 요약표 자동 생성.
   - 문맥에 맞는 이모지와 사진/스티커 배치 가이드 제공.
4. **원클릭 스마트에디터 복사**:
   - 볼드체, 소제목, 요약표, 문단 간격이 그대로 유지된 채 네이버 스마트에디터 ONE에 [Ctrl + V]로 붙여넣어집니다.
6. **의존성 없는 무설치 단일 실행 파일 (.exe)**:
   - 파이썬이나 별도 라이브러리 설치 필요 없이 `공인중개사_블로그_생성기.exe` 단 하나만으로 즉시 작동합니다.

## 🚀 실행 방법

### `공인중개사_블로그_생성기.exe` 더블클릭
- 별도 설치 없이 단일 실행 파일을 더블클릭하면 즉시 실행됩니다.

---

## 🔑 초기 설정 (최초 1회)

1. 프로그램 상단 우측의 **`⚙️ 환경 설정 (API 키)`** 버튼 클릭
2. Google Gemini API 키를 입력 (무료 발급 가능)
3. 부동산 사무소 상호명, 대표자명, 전화번호를 입력하면 글 하단에 자동으로 멋진 상담 배너 문구가 포함됩니다.


## 🛠️ 사용 및 빌드 안내

### 1. 초고속 포터블 (0.5초 즉시 실행) 빌드 (추천):
```bash
python build_portable.py
```
- `dist/공인중개사_블로그_생성기/` 폴더가 생성됩니다.
- 폴더 안의 `공인중개사_블로그_생성기.exe` 또는 루트의 `실행하기.bat`를 더블클릭하면 **압축 해제 딜레이 없이 0.5초 만에 즉시 실행**됩니다.

### 2. 단일 파일 (.exe 1개) 빌드 (패키지 다이어트 적용):
```bash
python build_portable.py --onefile
```
- 불필요한 대형 패키지(matplotlib, tkinter 등)가 제외되어 기존보다 가볍고 빠른 단일 `.exe`가 생성됩니다.
