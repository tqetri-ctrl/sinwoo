# 🏠 공인중개사 네이버 블로그 글 생성기 (AI 부동산 브리핑)

부동산 새 소식, 시장 동향, 분양 공고문, 보도자료를 **주제나 파일만 넣으면 최신 기사를 검색하고 이모티콘과 서식을 곁들인 네이버 블로그 글**로 자동 완성해주는 **Windows 무설치 단일 파일(.exe) 포터블 프로그램**입니다.

---

## ✨ 주요 기능 및 특징

1. **초등학생도 쓸 수 있는 초간단 1-2-3-4 단계 UI**:
   - **1단계**: 글감 넣기 (주제만 입력해 기사 검색 or 보도자료/공고문 파일 넣기)
   - **2단계**: 말투(톤앤매너) 고르기 (다정한 이웃 / 전문 브리핑 / 투자 코치 / 3분 요약)
   - **3단계**: `✨ 블로그 글 만들기` 클릭
   - **4단계**: 스마트에디터 스타일 미리보기 확인 후 `📋 네이버 블로그에 바로 붙여넣기 복사`
2. **실시간 인터넷 기사/뉴스 검색 기반 작성 (Search Grounding)**:
   - "2026년 청약 제도 개편안"처럼 주제만 치면, 실시간 인터넷 기사와 정책 팩트를 자동으로 수집하여 작성.
3. **다양한 첨부파일 정밀 분석 (멀티모달 AI)**:
   - 보도자료, 공고문, 단지 배치도, 사진 등 다양한 파일(PDF, HWP, HWPX, DOCX, TXT, PNG, JPG)을 드래그앤드롭하여 핵심 내용을 반영.
4. **네이버 블로그 최적화 서식 & 플레이스홀더 제안**:
   - 문맥에 맞는 자연스러운 이모지 삽입
   - 스티커 및 사진 배치 가이드 (`[✨ 추천 스티커: 환하게 인사하는 캐릭터]`, `[📸 추천 사진: 단지 전경]`) 자동 제안
5. **원클릭 스마트에디터 복사**:
   - 볼드체, 소제목, 문단 간격이 그대로 유지된 채 스마트에디터 ONE에 [Ctrl + V]로 들어갑니다.
6. **의존성 없는 무설치 단일 실행 파일 (.exe)**:
   - 파이썬이나 별도 라이브러리 설치 필요 없이 `공인중개사_블로그_생성기.exe` 단 하나만으로 즉시 작동합니다.

---

## 🚀 실행 방법

### `공인중개사_블로그_생성기.exe` 더블클릭
- 별도 설치 없이 단일 실행 파일을 더블클릭하면 즉시 실행됩니다.

---

## 🔑 초기 설정 (최초 1회)

1. 프로그램 상단 우측의 **`⚙️ 환경 설정 (API 키)`** 버튼 클릭
2. Google Gemini API 키를 입력 (무료 발급 가능)
3. 부동산 사무소 상호명, 대표자명, 전화번호를 입력하면 글 하단에 자동으로 멋진 상담 배너 문구가 포함됩니다.
